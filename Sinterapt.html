Software by Tomographic

I'm beginning user testing of my macOS application for analysis of APT data. Many years ago this app was called "Apex", and before that "Adam". It's rebranded as "Sinterapt".

"Sinter" is a reference to the fact that the scripting interface is where much of the value of the application lives, while also being a nod to a materials manufacturing process.
